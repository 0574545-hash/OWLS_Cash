# OWLS Cash для iOS

Нативная версия трекера расходов на SwiftUI. Повторяет веб-версию из корня
репозитория: те же экраны, те же цвета и шрифты, тот же формат файла копии.

## Что нужно

Xcode из Mac App Store. Он бесплатный, весит около десяти гигабайт, ставится
час или больше. После первого запуска Xcode попросит доустановить компоненты
и пароль администратора.

Счёт разработчика **не нужен**, пока приложение запускается в симуляторе.
Он понадобится только для установки на настоящий iPhone.

## Запуск

1. Открыть `ios/OWLSCash.xcodeproj` двойным щелчком.
2. Вверху выбрать симулятор, например iPhone 16.
3. Нажать треугольник или сочетание клавиш Command и R.

Если Xcode покажет ошибку подписи, зайти в настройки цели, вкладка
Signing & Capabilities, и снять галочку автоматической подписи. Для симулятора
подпись не требуется.

## На свой iPhone без платного счёта

1. Подключить телефон кабелем и выбрать его в списке устройств.
2. Xcode, Settings, Accounts, добавить свой Apple ID. Это бесплатно.
3. В настройках цели выбрать эту команду в поле Team.
4. Сменить `PRODUCT_BUNDLE_IDENTIFIER` на что-то своё, например `com.вашафамилия.owlscash`.
5. На телефоне: Настройки, Основные, VPN и управление устройством, доверять
   своему сертификату.

Сборка с бесплатным счётом перестаёт запускаться через семь дней. Лечится
повторной установкой из Xcode.

## Файлы

```
Info.plist                  шрифты, ориентация, экран запуска
OWLSCash.xcodeproj          проект
OWLSCash/Sources/
  Design.swift              токены OWLS: цвет, шрифт, радиусы, движение
  Store.swift               данные, расчёты, копия в файл
  OWLSCashApp.swift         точка входа и заставка
  RootView.swift            вкладки и таб-бар
  TodayView.swift           суммы и форма внесения
  HistoryView.swift         история по дням
  DashboardView.swift       кольца по категориям
  SettingsView.swift        категории и копия данных
OWLSCash/Fonts/             Unbounded и Manrope
OWLSCash/Assets.xcassets/   иконка приложения и знак совы
```

## Совместимость с веб-версией

Файл копии `OWLS Cash.json` одинаковый в обеих версиях. Копию из веб-версии
можно восстановить здесь и наоборот, данные не потеряются.

## Чего пока нет

- Перетаскивание категорий в настройках. Метод `moveCategories` в `Store` готов,
  интерфейс к нему не подключён.
- Голосовой ввод и модель на устройстве. Обсуждалось отдельно, требует iOS 26.
- Синхронизация через iCloud. Нативно это делается на CloudKit и заменит файл копии.

## Проверено и нет

Код написан, но **ни разу не собирался**: на машине стоят только инструменты
командной строки, без Xcode нет ни iOS SDK, ни симулятора. Синтаксис проверен
разбором каждого файла, имена шрифтов сверены с внутренними именами в самих
файлах шрифтов. Ошибки компиляции возможны, и первые сборки почти наверняка
их покажут.
